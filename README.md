# 📚 Documentação do Repositório: AppReactAspNetCore

Este repositório contém um projeto full-stack desenvolvido com React para o frontend e ASP.NET Core para o backend, visando a criação de uma aplicação robusta e integrada.

## 🧩 Estrutura do Repositório

### Frontend: React (pro-atividade-app)

O frontend é construído com o Create React App e está localizado em:
/front/pro-atividade-app

#### Funcionalidades Principais:
- **Interface Intuitiva**: Desenvolvida com React, proporcionando uma experiência de usuário fluida.
- **Comunicação com API**: Utiliza `fetch` para interagir com a API backend.
- **Gerenciamento de Estado**: Implementa o gerenciamento de estado para controle eficiente dos dados.

#### Scripts Disponíveis:
- `npm start`: Inicia o aplicativo em modo de desenvolvimento.
- `npm test`: Executa os testes.
- `npm run build`: Cria a versão otimizada para produção.

### Backend: ASP.NET Core (ProAtividade.API)

O backend é uma API RESTful desenvolvida com ASP.NET Core e está localizado em:
/back/src/ProAtividade.API

#### Funcionalidades Principais:
- **Controladores**: Implementa controladores para gerenciar fornecedores, produtos e suas relações.
- **Modelo de Dados**: Utiliza Entity Framework Core para interagir com o banco de dados.
- **Validações**: Emprega FluentValidation para garantir a integridade dos dados.

#### Endpoints Principais:
- `/api/Fornecedores`: Gerencia operações relacionadas a fornecedores.
- `/api/Produtos`: Gerencia operações relacionadas a produtos.
- `/api/ProdutoFornecedores`: Gerencia as relações entre produtos e fornecedores.
